# Usage Tray 사용 안내

다운로드와 프로젝트 소개는 [README](../README.md), 빌드·검증·CLI 옵션은
[개발 안내](development.md), 연결·표시 문제는 [문제 해결](troubleshooting.md)을 참고합니다.

## 실행과 종료

Windows에서는 `usage-tray.exe`를 계속 사용할 폴더에 두고 실행합니다.
일반 실행은 로그인 자동 실행을 등록하지 않습니다. 트레이가 보이지 않으면 작업표시줄의
오버플로(∧)를 확인하고 아이콘을 작업표시줄로 끌어다 놓습니다.
종료하려면 트레이 아이콘을 우클릭하고 **끝내기**를 선택합니다.
여러 서비스의 아이콘이 있으면 각 아이콘은 별도 프로세스이므로 각각 종료합니다.

Windows에서 자동 실행 등록과 지금 실행을 함께 하려면 해당 폴더의 PowerShell에서 실행합니다.

```powershell
.\usage-tray.exe -install
```

이 명령은 시작프로그램 바로가기를 만들고 트레이 아이콘을 작업표시줄에 표시하도록 설정합니다.
자동 실행 해제는 `.\usage-tray.exe -uninstall`입니다. 실행 파일을 옮겼다면 새 위치에서 다시 등록합니다.
설정 화면의 **일반 → 로그인 시 실행 → 저장**으로도 자동 실행을 변경할 수 있습니다.

macOS 배포본은 다음과 같이 압축을 풀어 옮긴 뒤 엽니다.

```bash
unzip UsageTray-macos-universal.zip
mv UsageTray.app /Applications/
open /Applications/UsageTray.app
```

자동 실행은 앱 번들 실행 시 설정 화면에서도 변경할 수 있습니다. CLI로 등록하고 지금 실행하려면
`/Applications/UsageTray.app/Contents/MacOS/usage-tray -install`을 사용합니다.
해제는 같은 경로에 `-uninstall`을 지정합니다. 앱을 옮기면 새 위치에서 다시 등록합니다.
로그인 항목 등록 시 macOS가 **시스템 이벤트 제어 권한**을 요청하면 허용해야 합니다.
보안 경고나 로그인 항목 권한 문제가 생기면
[문제 해결](troubleshooting.md)을 참고합니다. Dock 대신 메뉴바에 표시합니다.
메뉴바 아이콘을 눌러 **상세 보기 · 설정 · 지금 갱신 · 아이콘 모양 · 끝내기**를 사용합니다.
아래의 한 번 클릭 요약 카드와 더블클릭 동작은 Windows 안내입니다.

## 트레이와 요약 카드

Windows는 사용하는 서비스마다 아이콘 하나를 표시합니다. macOS는 한 아이콘에
현재 표시 기준상 남은량이 가장 적은 서비스를 표시하며 메뉴와 상세 화면에는 연결 대상을 함께 보여줍니다.
아이콘 위에 마우스를 올리면 남은량과 초기화 정보를 간단히 볼 수 있습니다.

| Windows 조작 | 동작 |
|---|---|
| 한 번 클릭 | 한도별 3줄 요약 카드를 열거나 닫습니다 |
| 더블클릭 | 연결된 서비스를 합친 상세 화면을 브라우저에서 엽니다 |
| 우클릭 | 상세 보기·설정·업데이트 확인·지금 갱신·아이콘 모양·폴더 열기·끝내기 메뉴를 엽니다 |

요약은 **잔량 → 초기화 날짜와 남은 시간 → 서비스·한도명** 순서입니다.
더블클릭과 구분하기 위해 Windows의 더블클릭 대기 시간 뒤에 열립니다.
오른쪽 위의 **새로고침 / 설정** 아이콘으로 바로 갱신하거나 설정 화면을 엽니다.
카드 밖을 클릭하거나 트레이 아이콘을 다시 한 번 클릭하면 닫힙니다.
카드 위에 마우스를 두면 유지되고, 벗어난 뒤 약 7초 후에도 자동으로 닫힙니다.
단기 한도의 잔량과 초기화 정보가 모두 없으면 그 항목은 생략하지만 0%는 표시합니다.
초기화 시각이 지났어도 새 값을 받기 전에는 **초기화 갱신 대기**로 표시합니다.

**아이콘 모양**은 도넛(기본)과 숫자만 중에서 선택합니다.
도넛의 링 길이는 남은 비율이며, 숫자 `64`는 64% 남음을 뜻합니다. 조회된 값이 없으면 `-`입니다.
Windows 숫자는 Tahoma 8pt의 보통 굵기를 사용하고, 글꼴이 없으면 Segoe UI로 대체합니다.
9·99·100 모두 같은 글자 크기와 원래 비율을 유지하며 가로 가운데에 정렬합니다.
최종 트레이 크기에서 직접 그리고, 세로 위치는 중앙보다 조금 위로 맞춥니다(16px 아이콘 기준 1px).
선택은 저장되어 재시작 후 유지되고 Windows의 다른 서비스 아이콘에도 반영됩니다.

| 표시 위치 | 잔량 강조 기준 |
|---|---|
| 도넛·숫자 아이콘 | 20% **미만**이면 빨강 |
| 클릭 요약 카드 | 20% **이하** 주황, 10% **이하** 빨강 |

## 상세 화면과 기록 그래프

상세 화면은 로컬 브라우저에서 열며 세 화면으로 나뉩니다.

| 화면 | 내용 |
|---|---|
| 한도 현황 `/` | 잔량·초기화 시각, 잔여 한도 추이, 사용 전망 |
| 토큰 통계 `/tokens` | 로컬 기록에서 집계한 일별·모델별·프로젝트별 토큰 통계 |
| 설정 `/settings` | 표시·알림·자동 실행, 수집 상태와 업데이트 |

한도 현황에서 **에이전트 · 한도 · 기간**을 고릅니다. 실제 관측 기록은 최대 30일 보관합니다.
전체 기간 그래프는 최근 1일·7일·30일을 각각 30분·4시간·1일 구간으로 묶어
각 구간의 마지막 잔량을 표시합니다. 기록이 없는 시간에는 값을 만들어 넣지 않습니다.
초기화 주기가 바뀌거나 빈 구간이 있으면 선을 잇지 않습니다.

기록이 기간 일부에만 있으면 **기록 구간 확대**가 기본으로 켜집니다.
위의 작은 그래프는 전체 기간과 확대 위치를 보여주고, 아래 그래프는 실제 기록 구간을 크게 표시합니다.
확대 시 표시 간격도 다시 조절합니다. 같은 버튼으로 전체 기간 보기에 돌아갑니다.
이 표시는 원본 기록과 소진 예상 계산을 바꾸지 않습니다.

마우스를 올리거나 터치하면 해당 구간의 마지막 관측 시각·잔량·출처·초기화 정보를 확인합니다.
키보드의 Tab으로 관측점을 선택할 수도 있습니다. Escape나 그래프 바깥 클릭으로 설명을 닫습니다.
기록이 없는 구간에서는 관측점 설명을 표시하지 않습니다. 제목 옆 `?`에도 설명이 있습니다.
화면 자동 갱신 중에도 선택한 기록 조건과 저장하지 않은 설정은 유지됩니다.

## 사용 전망 읽기

사용 전망은 선택한 서비스·한도를 기준으로 하며 그래프 기간 필터와 별도로 계산합니다.
상단에는 예상 소진 시점을, 하단에는 **관측 기록**과 **사용 예산**을 구분해 표시합니다.
**관측 사용량**은 표시된 시작·종료 시각 사이에 정수로 저장된 잔량이 감소한 양입니다.
단위 `%p`는 전체 한도 기준의 변화량으로, 80%에서 70%가 되면 10%p를 사용한 것입니다.
이는 실제 토큰 수가 아닙니다.

**현재 환산 속도**는 관측 구간의 감소량을 24시간 기준으로 환산한 값입니다.
지난 하루의 실제 사용량 합계로 읽지 않습니다.
**초기화까지의 하루 예산**은 남은 한도를 초기화까지 균등하게 나눠 쓰는 하루 목표입니다.
초기화까지 하루 미만이면 시간당 예산도 보여줍니다.
조기 소진이 예상되면 하루 예산과 현재 환산 속도에서 줄일 비율을 함께 안내합니다.

소진 예상은 현재 주기에서 **실제 관측 3개 이상 · 관측 기간 30분 이상 · 잔량 1%p 이상 감소**가
있어야 계산합니다. 한도 주기와 미래의 초기화 시각도 필요하며 마지막 관측은 30분 이내여야 합니다.
초기화 시각·주기 길이·출처가 바뀌거나 잔량이 회복되면 새 관측 구간을 시작합니다.
오래된 값, 캐시·직전값 등 현재 조회가 실제 최신 관측과 일치하지 않으면 예상과 예산을 숨깁니다.
조건이 부족하면 화면에 사유를 표시합니다. 하루 예산은 신선한 잔량과 초기화 시각이 있으면
소진 예상이 준비되기 전에도 표시할 수 있습니다.
소진 시점은 이 관측 구간의 평균 감소 속도가 계속된다는 가정입니다.

## 설정과 알림

트레이 메뉴나 상세 화면에서 **설정**을 엽니다. **트레이 · 알림 · 일반** 항목을 변경한 뒤
하단의 공통 **저장**을 누르면 재시작 없이 반영됩니다. macOS 자동 실행은 `.app` 안에서 실행해야 지원합니다.
변경한 앱 설정과 자동 실행만 저장하며 **변경 취소**는 마지막 저장 값으로 되돌립니다.
일부 저장이 실패하면 성공한 항목을 안내하고 실패한 변경은 유지하여 다시 저장할 수 있습니다.
저장하지 않은 상태로 다른 화면으로 이동하면 확인을 요청합니다.

| 설정 | 동작 |
|---|---|
| 표시할 한도 | 주간 / 단기 / 가장 부족한 한도. 선택한 한도 정보가 없으면 값 없음 |
| 에이전트 표시 | 트레이에서 숨기거나 다시 표시. 수집과 상세 화면은 유지 |
| 아이콘 모양 | 도넛 / 숫자만 |
| 알림 | 전체 켜기·끄기, 한도별 사용 여부·1~99% 기준·회복 알림, Codex 한도 도달 알림 |
| 고급 설정 | 수집 간격을 1~60분으로 지정 |
| 일반 | 로그인 시 실행을 선택하고 공통 저장으로 등록·해제 |
| 앱 정보 | 수집 상태·마지막 성공 시각·업데이트 확인 |

모든 에이전트를 숨겨도 설정 진입용 아이콘 하나는 남습니다.
알림 설정은 연결된 서비스의 한도를 먼저 보여주며 다른 대상은 접힌 영역에서 설정합니다.
잔량이 설정 기준 **미만**이 되면 한 번 알립니다. 기준과 같은 값에서는 새 알림이 발생하지 않습니다.
알림을 보낸 후 잔량이 **기준+10%p 이상(최대 100%)**으로 회복하면 다시 알릴 수 있는 상태가 되고,
회복 알림을 켰을 때 회복 메시지도 보냅니다. 기본 기준은 단기 10%, 주간·Antigravity 20%입니다.
Codex의 별도 이용 제한은 한도 도달과 해제를 알립니다.
업데이트는 버튼을 눌러 최신 릴리스와 변경 내용을 확인하고 다운로드 페이지를 엽니다.
자동 설치는 하지 않으며 로컬 `dev` 빌드는 버전 비교를 하지 않습니다.

## 연결 조건과 데이터 출처

별도 계정을 등록하는 대신 이미 로그인한 클라이언트의 자격증명과 로컬 기록을 읽습니다.
Windows는 Claude Code·Codex, macOS는 여기에 Antigravity를 지원합니다.
Claude는 프로젝트·설정·자격증명 흔적, Codex는 `~/.codex/auth.json` 존재로 대상을 발견하므로
아이콘이 나타났다는 사실만으로 로그인이 유효하다는 뜻은 아닙니다. 발견한 대상이 없으면 종료합니다.
Antigravity는 설치 흔적으로 발견하며 실제 조회에는 실행 중인 로컬 언어 서버가 필요합니다.

Claude·Codex의 한도는 서비스의 사용량 경로에서 읽습니다. 실패 시 가능한 로컬 기록이나 직전값을
보여주고 출처와 경과 시간을 표시합니다. **정상 수집 / 기록·캐시 / 로그인 문제 / 수집 실패**와
마지막 성공 시각을 확인합니다. 로컬 토큰 통계와 서비스 한도는 서로 다른 자료이며,
토큰 합계로 남은 한도를 역산하지 않습니다. Antigravity는 모델별 잔량만 읽고 토큰 통계는 수집하지 않습니다.

지금 갱신을 눌러도 최소 조회 간격은 Claude 3분, Codex·Antigravity 2분입니다.
Windows Claude는 2분 이내 statusline 캐시가 있으면 활용합니다.
Claude의 HTTP 429·503 응답에는 5분부터 두 배씩 최대 30분까지 대기하는 백오프가 적용됩니다.
자격증명 경로·인증 오류·Keychain 권한은 [문제 해결](troubleshooting.md)을 참고합니다.

## 저장 위치

Windows는 `%LOCALAPPDATA%\usage-tray\`, macOS는 `~/Library/Application Support/usage-tray/`입니다.
트레이 메뉴의 **폴더 열기**로 확인할 수 있습니다.

| 파일 | 내용 |
|---|---|
| `settings.json` | 표시·수집·알림 설정, 프로세스 간 공통 |
| `state.json` · `status.txt` | 상태와 텍스트 요약 |
| `tokens.json` · `tokens-cache.json` | 토큰 집계와 증분 집계 캐시 |
| `history.json` | 실제 사용량 관측 기록 |
| `usage-tray.log` | 실행·수집 로그 |
| `heartbeat-<agent>` | 서비스별 프로세스 생존 표시 |

Windows의 서비스별 프로세스는 `state-claude.json`, `tokens-cache-codex.json`처럼
상태·요약·토큰·캐시·이력 파일에 `-<agent>`를 붙입니다. 단일 서비스의 일반 실행과
macOS의 기본 통합 실행은 접미사가 없습니다. `-only`로 실행하면 하나여도 접미사가 붙습니다.
설정과 사용량 이력에는 로그인 토큰을 저장하지 않습니다.
`USAGE_TRAY_DATA_DIR`로 저장 폴더를 바꿀 수 있지만 **로컬 포트와 자격증명은 분리되지 않습니다**.
개발용 폴더만 바꾸고 기존 앱과 동시에 실행하지 않습니다. 자세한 검증 절차는 [개발 안내](development.md)에 있습니다.
