# Usage Tray v0.1.1

## 변경 내용

- 상세 화면 상단과 설정의 앱 정보에 현재 실행 중인 버전을 표시합니다.
- 설정과 트레이 메뉴의 **릴리스 보기**를 누르면 GitHub 최신 릴리스 페이지가 열립니다. 앱 안에 길게 표시하던 마크다운 변경 내역을 제거했습니다.
- Codex 숫자 아이콘의 기본 녹색을 `#087F68`로 진하게 조정했습니다. 도넛 색상과 다른 서비스의 색상, 글꼴 크기·굵기·정렬은 유지합니다. 잔량 20% 미만은 기존 빨간색으로 표시합니다.

## 다운로드와 실행

- **Windows x64:** `UsageTray-windows-amd64.zip`을 풀고 `usage-tray.exe`를 실행합니다. 단일 exe도 별도로 제공합니다.
- **macOS Apple Silicon / Intel:** `UsageTray-macos-universal.zip`을 풀고 `UsageTray.app`을 응용 프로그램 폴더로 옮겨 실행합니다.
- 기존 앱을 종료한 뒤 같은 위치의 실행 파일을 교체합니다. 설정과 수집 기록은 기존 데이터 폴더에 유지됩니다.
- 자동 설치는 지원하지 않습니다. Windows 코드 서명과 macOS 개발자 공증은 적용되어 있지 않습니다.

Windows zip과 macOS 앱 번들에 제삼자 라이선스 고지가 포함됩니다. 단일 exe를 배포할 때는 같은 릴리스의 `THIRD_PARTY_NOTICES.txt`도 함께 제공합니다.
