# Usage Tray v0.1.0

`dancingowl/token_usage_tray`의 첫 공개 배포입니다.
[inging88/usage_tray](https://github.com/inging88/usage_tray)를 원작자의 허락을 받아 독립 저장소로 옮겼으며, 기존 코드와 커밋 이력을 보존했습니다.

## 다운로드

- **Windows x64:** `UsageTray-windows-amd64.zip`을 계속 사용할 폴더에 풀고 `usage-tray.exe`를 실행합니다. 단일 실행 파일도 별도로 제공합니다.
- **macOS Apple Silicon / Intel:** `UsageTray-macos-universal.zip`을 풀고 `UsageTray.app`을 응용 프로그램 폴더로 옮겨 실행합니다.
- 이미 로그인한 Claude Code·Codex 계정이 필요합니다. Antigravity는 macOS에서만 지원합니다.

## 주요 기능

- 남은 사용 한도와 초기화 시각을 트레이·메뉴바에서 확인합니다.
- Windows 트레이 한 번 클릭 요약, 더블클릭 상세 화면, 도넛·숫자 아이콘을 제공합니다.
- Windows 숫자는 Tahoma 8pt를 최종 아이콘 크기에서 직접 그립니다. 9·99·100의 글자 크기를 유지하고 가로 가운데에 정렬합니다.
- 한도 이력의 기간 필터·기록 구간 확대·호버 상세와 사용 전망을 제공합니다.
- 관측 사용량과 하루 환산 속도를 구분하고, 초기화까지의 하루 예산과 현재 속도 유지 시 예상 소진 시점을 표시합니다.
- 로컬 대화 기록의 토큰 통계, 임계값 알림, 로그인 자동 실행을 설정할 수 있습니다.
- 업데이트 확인으로 최신 릴리스와 다운로드 페이지를 안내합니다. 자동 설치는 지원하지 않습니다.

## 실행 안내

실행 파일에 Go·Node.js 설치는 필요하지 않습니다. 배포 파일에는 Windows 코드 서명이나 macOS 개발자 공증이 적용되어 있지 않습니다. OS의 보안 정책에 따라 실행이 차단될 수 있습니다.

Windows zip과 macOS 앱 번들에는 제삼자 라이선스 고지가 포함되어 있습니다. 단일 exe를 배포하는 경우 같은 릴리스의 `THIRD_PARTY_NOTICES.txt`도 함께 제공합니다.

[사용법](https://github.com/dancingowl/token_usage_tray/blob/v0.1.0/docs/usage.md) · [문제 해결](https://github.com/dancingowl/token_usage_tray/blob/v0.1.0/docs/troubleshooting.md)

서비스의 비공개 조회 경로와 로컬 기록에 의존하므로 서비스 변경에 따라 조회가 실패할 수 있습니다. 소진 시점은 관측 속도가 유지된다는 가정의 추정치입니다.
