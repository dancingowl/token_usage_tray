# Usage Tray v0.2.0

## 변경 내용

- **연결 자동 발견:** 로그인한 서비스가 없어도 연결 대기 아이콘과 상세 화면을 유지합니다. 로그인 흔적을 약 15초마다 확인해 자동 연결하며, Windows에서는 서비스가 늘어나면 서비스별 아이콘으로 전환합니다.
- **화면 갱신:** 앱 재시작이나 화면 변경을 감지해 다시 불러옵니다. 저장하지 않은 설정이나 저장 중인 작업이 있으면 먼저 저장하거나 취소하도록 안내합니다.
- **조회 조건 기억:** 한도 이력의 에이전트·한도·기간·확대 여부와 토큰 통계의 조회 조건을 같은 브라우저와 로컬 주소에서 기억합니다.
- **토큰 기간과 필터:** 최근 7·14·30일, 모델·프로젝트 필터를 그래프와 합계·표에 함께 적용합니다. 전체 보기로 상위 6개 제한을 해제할 수 있습니다.
- **사용 전망:** 전체 관측과 최근 구간의 사용 속도를 비교합니다. 속도 변화가 크면 소진 시점 추정을 보류하고 관측 사용량과 하루 예산은 계속 표시합니다.
- **알림 일시 중지:** 1시간 또는 오늘까지 알림을 쉬고 종료 시각에 자동 재개합니다. 기존 알림 기준은 유지합니다.
- **밝기와 테마:** 상단 테마 메뉴에서 시스템 설정·밝게·어둡게를 선택하면 즉시 별도로 저장합니다. 상세 화면과 Windows 요약 카드에 반영하며, 트레이 숫자는 작업표시줄 밝기에 맞춥니다.
- **갱신 상태:** 지금 갱신의 조회 중·완료·실패를 구분하고, 최소 조회 간격이나 요청 제한으로 기다릴 때 다음 조회 시각을 안내합니다.

설정 화면의 접힌 영역을 없애 수집 간격·서비스별 알림·앱 정보를 바로 확인할 수 있습니다. 토큰 그래프에는 마우스·터치·키보드로 확인하는 상세 툴팁을 추가했고, 하단 정보는 마지막 집계 시각으로 정리했습니다.

여러 서비스 창에서 설정을 동시에 저장해도 테마와 다른 설정이 유실되지 않도록 프로세스 간 잠금을 적용했습니다. 갱신 완료 직후의 요청 누락과 서비스별 최소 조회 간격 계산도 보완했습니다.

## 다운로드와 업데이트

- **Windows x64:** [UsageTray-windows-amd64.zip](https://github.com/dancingowl/token_usage_tray/releases/download/v0.2.0/UsageTray-windows-amd64.zip)을 풀고 `usage-tray.exe`를 실행합니다. 단일 exe도 별도로 제공합니다.
- **macOS Apple Silicon / Intel:** [UsageTray-macos-universal.zip](https://github.com/dancingowl/token_usage_tray/releases/download/v0.2.0/UsageTray-macos-universal.zip)을 풀고 `UsageTray.app`을 응용 프로그램 폴더로 옮겨 실행합니다.
- 기존 앱을 모두 종료한 뒤 같은 위치의 실행 파일 또는 앱 번들을 교체합니다. 설정과 수집 기록은 기존 데이터 폴더에 유지됩니다. 자동 설치는 지원하지 않습니다.
- Windows 코드 서명과 macOS 개발자 공증은 적용되어 있지 않습니다. 실행이 차단되면 아래 문제 해결 문서를 확인하세요.

Windows zip과 macOS 앱 번들에는 제삼자 라이선스 고지가 포함됩니다. 단일 exe를 배포할 때는 같은 릴리스의 `THIRD_PARTY_NOTICES.txt`도 함께 제공합니다. `SHA256SUMS.txt`에는 exe·두 zip·라이선스 고지의 SHA-256 해시가 들어 있습니다.
