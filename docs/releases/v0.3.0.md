# Usage Tray v0.3.0

## 변경 내용

- **Windows 자동 업데이트:** x64 정식 버전이 시작 직후와 6시간마다 최신 정식 GitHub Release를 확인합니다. 새 버전은 다운로드와 검증 후 실행 파일을 교체하고 앱을 재시작합니다. 설정의 앱 정보에서 상태·오류와 다음 확인 시각을 확인할 수 있습니다. 실패하면 다음 주기에 다시 확인하며 재시작해도 확인 대기를 유지합니다.
- **배포 파일 검증:** 지정 저장소·릴리스 태그에 맞는 HTTPS 주소와 파일 크기, 같은 릴리스의 `SHA256SUMS.txt`에 기록한 SHA-256을 확인합니다. 별도 교체 도우미가 앱 종료·교체·재시작을 수행하고 실패 시 기존 파일 복원을 시도합니다.
- **설정 즉시 저장:** 트레이 표시·알림·수집 간격·로그인 자동 실행·테마를 변경하면 바로 저장합니다. 숫자는 유효한 입력을 마친 뒤 저장하며 저장 중·완료·오류와 재시도를 안내합니다. 공통 저장·변경 취소 버튼과 미저장 변경 확인을 제거했습니다.

개발용 `dev` 빌드는 자동 업데이트를 건너뜁니다. macOS는 릴리스 페이지에서 파일을 내려받아 수동으로 교체합니다.

## 다운로드와 업데이트

- **Windows x64:** [UsageTray-windows-amd64.zip](https://github.com/dancingowl/token_usage_tray/releases/download/v0.3.0/UsageTray-windows-amd64.zip)을 계속 사용할 폴더에 풀고 `usage-tray.exe`를 실행합니다. 단일 exe도 별도로 제공합니다.
- **macOS Apple Silicon / Intel:** [UsageTray-macos-universal.zip](https://github.com/dancingowl/token_usage_tray/releases/download/v0.3.0/UsageTray-macos-universal.zip)을 풀고 `UsageTray.app`을 응용 프로그램 폴더로 옮겨 실행합니다. 자동 설치는 지원하지 않습니다.
- 이전 버전에서 v0.3.0으로 이동할 때는 기존 앱을 모두 종료한 뒤 같은 위치의 실행 파일 또는 앱 번들을 수동 교체합니다. 설정과 수집 기록은 기존 데이터 폴더에 유지됩니다.
- Windows 업데이트에는 실행 파일 폴더의 쓰기 권한이 필요합니다. OS 보안 정책이나 보안 제품의 실행 차단은 우회하지 않습니다. Windows 코드 서명과 macOS 개발자 공증은 적용되어 있지 않습니다.

Windows zip과 macOS 앱 번들에는 `THIRD_PARTY_NOTICES.txt`가 포함됩니다. 단일 exe를 배포할 때는 같은 릴리스의 고지도 함께 제공합니다. `SHA256SUMS.txt`에는 exe·두 zip·고지의 SHA-256이 들어 있습니다. 이 해시는 같은 GitHub Release에서 제공하며 별도 서명 키로 인증한 업데이트 메타데이터가 아닙니다.

이 프로젝트는 원작자의 허락을 받아 [inging88/usage_tray](https://github.com/inging88/usage_tray)의 코드와 이력을 보존한 독립 저장소 [dancingowl/token_usage_tray](https://github.com/dancingowl/token_usage_tray)입니다. 이번 변경은 기존 외부 라이브러리의 출처·README·라이선스와 제삼자 고지를 유지합니다.

자동 업데이트는 exe만 교체하며 기존 `THIRD_PARTY_NOTICES.txt`는 유지합니다. 이번 버전은 v0.2.0과 의존성·고지가 같지만, 향후 고지가 바뀌는 릴리스는 새 zip을 받아 재설치해야 합니다.
