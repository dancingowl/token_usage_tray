# Usage Tray v0.4.0

## 변경 내용

- **Codex 크레딧 잔액:** 정기 사용 한도와 별도로 크레딧 잔액을 한도 현황과 트레이 요약에 표시합니다. 정상 조회한 0과 조회 실패·누락·오래된 값의 **확인 불가**를 구분하며, 무제한 응답도 구분합니다.
- **기존 그래프에 잔액 추이 통합:** 한도 현황의 **항목 → 크레딧 잔액**에서 최근 1일·7일·30일의 잔액과 기간 중 감소량·증가량을 확인합니다. 계정 변경이나 조회 공백을 가로질러 선을 연결하거나 사용량으로 계산하지 않습니다. 이력은 이 버전에서 수집을 시작한 시점부터 쌓입니다.
- **한도 카드 정리:** 첫 줄에는 잔량과 서비스·요금제를, 둘째 줄에는 초기화 정보와 크레딧 잔액을 표시합니다. 중복된 **실시간** 문구를 제거하고, 좁은 화면에서는 정보가 자연스럽게 줄바꿈됩니다. 캐시·이용 제한 등 예외 상태는 유지합니다.
- **토큰 통계 유지:** 기존 로컬 기록 기반 집계에 크레딧을 별도로 더하지 않습니다. 크레딧 잔액 변화는 결제 내역이나 청구 금액이 아니며, 주간 초기화 기준의 예산·소진 예상도 적용하지 않습니다.

## 다운로드와 업데이트

- **Windows x64:** [UsageTray-windows-amd64.zip](https://github.com/dancingowl/token_usage_tray/releases/download/v0.4.0/UsageTray-windows-amd64.zip)을 계속 사용할 폴더에 풀고 `usage-tray.exe`를 실행합니다. [단일 exe](https://github.com/dancingowl/token_usage_tray/releases/download/v0.4.0/usage-tray.exe)도 제공합니다.
- **macOS Apple Silicon / Intel:** [UsageTray-macos-universal.zip](https://github.com/dancingowl/token_usage_tray/releases/download/v0.4.0/UsageTray-macos-universal.zip)을 풀고 `UsageTray.app`을 응용 프로그램 폴더로 옮겨 실행합니다.
- Windows x64 v0.3.0 이상 정식 버전은 자동 업데이트를 지원합니다. 시작 직후와 6시간마다 최신 정식 릴리스를 확인하며, 실행 파일 폴더의 쓰기 권한이 필요합니다. 개발용 `dev` 빌드는 자동 업데이트를 건너뜁니다.
- macOS는 수동 업데이트를 사용합니다. 기존 앱을 모두 종료한 뒤 `UsageTray.app`을 교체합니다. Windows에서 수동 업데이트할 때도 기존 앱을 모두 종료한 뒤 같은 위치의 실행 파일을 교체합니다.
- **기존 설정과 수집 기록은 데이터 폴더에 유지됩니다.** Windows 코드 서명과 macOS 개발자 공증은 적용되어 있지 않습니다.

배포 파일은 같은 릴리스의 [SHA256SUMS.txt](https://github.com/dancingowl/token_usage_tray/releases/download/v0.4.0/SHA256SUMS.txt)로 확인할 수 있습니다. exe·두 zip·고지의 SHA-256을 제공하며 별도 서명 키로 인증한 업데이트 메타데이터는 아닙니다.

Windows zip과 macOS 앱 번들에는 [THIRD_PARTY_NOTICES.txt](https://github.com/dancingowl/token_usage_tray/releases/download/v0.4.0/THIRD_PARTY_NOTICES.txt)가 포함됩니다. 단일 exe를 배포할 때는 같은 릴리스의 고지도 함께 제공합니다. 자동 업데이트는 exe만 교체하며 기존 고지는 유지합니다. 이번 버전은 v0.3.1과 의존성·고지가 같습니다.

이 프로젝트는 원작자의 허락을 받아 [inging88/usage_tray](https://github.com/inging88/usage_tray)의 코드와 이력을 보존한 독립 저장소 [dancingowl/token_usage_tray](https://github.com/dancingowl/token_usage_tray)입니다. 기존 외부 라이브러리의 출처·README·라이선스와 제삼자 고지를 유지합니다.
