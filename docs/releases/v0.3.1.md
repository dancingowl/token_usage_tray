# Usage Tray v0.3.1

## 변경 내용

- **토큰 필터 정리:** 기간·모델·프로젝트를 바꾸면 즉시 반영되며, 중복된 **적용** 버튼을 제거했습니다. **필터 초기화**를 누르면 최근 14일·전체 모델·전체 프로젝트로 돌아가고 이 선택을 브라우저에 기억합니다.
- **전체 목록 기본 표시:** 모델별·프로젝트별 표의 상위 6개 제한과 **모델·프로젝트 전체 보기** 선택을 제거했습니다. 선택한 기간·필터에 맞는 전체 목록을 표시합니다.
- **화면 안내 정리:** 상단 갱신 시각 옆의 **자동 갱신** 문구와 설정 화면의 평시 안내 영역·마지막 구분선을 제거했습니다. 화면 자동 갱신과 설정 즉시 저장은 계속 동작하며, 잘못된 입력·저장 오류 안내와 실패한 변경 재시도는 유지합니다.
- **숫자 입력 오류 개선:** 유효하지 않은 숫자에서 포커스를 옮길 때 브라우저 경고가 다른 조작의 포커스를 빼앗지 않도록 개선했습니다. 입력 오류 표시는 유지하며 잘못된 값은 저장하지 않습니다.

## 다운로드와 업데이트

- **Windows x64:** [UsageTray-windows-amd64.zip](https://github.com/dancingowl/token_usage_tray/releases/download/v0.3.1/UsageTray-windows-amd64.zip)을 계속 사용할 폴더에 풀고 `usage-tray.exe`를 실행합니다. [단일 exe](https://github.com/dancingowl/token_usage_tray/releases/download/v0.3.1/usage-tray.exe)도 제공합니다.
- **macOS Apple Silicon / Intel:** [UsageTray-macos-universal.zip](https://github.com/dancingowl/token_usage_tray/releases/download/v0.3.1/UsageTray-macos-universal.zip)을 풀고 `UsageTray.app`을 응용 프로그램 폴더로 옮겨 실행합니다.
- Windows x64 **v0.3.0 정식 버전은 자동 업데이트로 v0.3.1을 받을 수 있습니다.** 시작 직후와 6시간마다 최신 정식 릴리스를 확인하며, 실행 파일 폴더의 쓰기 권한이 필요합니다. 개발용 `dev` 빌드는 자동 업데이트를 건너뜁니다.
- macOS는 수동 업데이트를 사용합니다. 기존 앱을 모두 종료한 뒤 `UsageTray.app`을 교체합니다. Windows에서 수동 업데이트할 때도 기존 앱을 모두 종료한 뒤 같은 위치의 실행 파일을 교체합니다.
- **기존 설정과 수집 기록은 데이터 폴더에 유지됩니다.** Windows 코드 서명과 macOS 개발자 공증은 적용되어 있지 않습니다.

배포 파일은 같은 릴리스의 [SHA256SUMS.txt](https://github.com/dancingowl/token_usage_tray/releases/download/v0.3.1/SHA256SUMS.txt)로 확인할 수 있습니다. exe·두 zip·고지의 SHA-256을 제공하며 별도 서명 키로 인증한 업데이트 메타데이터는 아닙니다.

Windows zip과 macOS 앱 번들에는 [THIRD_PARTY_NOTICES.txt](https://github.com/dancingowl/token_usage_tray/releases/download/v0.3.1/THIRD_PARTY_NOTICES.txt)가 포함됩니다. 단일 exe를 배포할 때는 같은 릴리스의 고지도 함께 제공합니다. 자동 업데이트는 exe만 교체하며 기존 고지는 유지합니다. 이번 버전은 v0.3.0과 의존성·고지가 같습니다.

이 프로젝트는 원작자의 허락을 받아 [inging88/usage_tray](https://github.com/inging88/usage_tray)의 코드와 이력을 보존한 독립 저장소 [dancingowl/token_usage_tray](https://github.com/dancingowl/token_usage_tray)입니다. 기존 외부 라이브러리의 출처·README·라이선스와 제삼자 고지를 유지합니다.
